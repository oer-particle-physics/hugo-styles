These guides explain changes that require attention when updating a lesson.
The **Update hugo-styles** workflow includes relevant guides directly in its pull
request, including changes from skipped releases. Detectable unfinished migrations
remain visible on later updates.

See [Updating Downstream Lessons]({{< relref "/docs/updates" >}}) for the update
workflow and its initial rollout. Maintainers adding guidance should follow
[hugo-styles Maintenance]({{< relref "/docs/hugo-styles-maintenance" >}}).
